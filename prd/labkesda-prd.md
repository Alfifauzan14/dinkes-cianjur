# PRD: Laboratorium Kesehatan Daerah (Labkesda)

## Tujuan
Menampilkan informasi layanan Laboratorium Kesehatan Daerah kepada publik sebagai bagian dari fasilitas kesehatan Dinkes Cianjur.

## Fitur
1. Halaman utama Labkesda.
2. Informasi layanan laboratorium.
3. Alamat dan kontak.
4. Jam operasional.

## Desain & UI
- **Typography:** Plus Jakarta Sans.
- **Warna:** 
    - Judul: #004F3B
    - Subjudul/Aksen: #009966
- **Layout:** Mengikuti struktur komponen `Faskes` (Header, List Layanan, Footer).
- **Responsivitas:** Mobile-first, Tailwind CSS v4.

## Struktur File
- View: `resources/views/labkesda.blade.php`
- Komponen: `resources/views/components/Labkesda/labkesda.blade.php`
